# FitBuddy como skill de Hermes Agent

La web (Next.js + Firestore + Vertex) se queda en el repo como archivo. El uso real es este skill.

- `fitbuddy/`: el skill (SKILL.md + referencias + plantillas).
- `PROMPT.md`: prompt autocontenido para que Hermes lo instale y arranque el onboarding. Se regenera desde `fitbuddy/`.

Datos del usuario: `~/.fitbuddy/` (perfil, planes semanales, log.csv, notas). No se versionan aquí.
