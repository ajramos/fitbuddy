
# FitBuddy - AI Functional Training Coach

FitBuddy is an agent-first web application that generates personalized functional training plans using Vertex AI (Gemini).

## Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Database**: Google Firestore (NoSQL)
- **Auth**: NextAuth.js (Google Provider)
- **AI**: Google Vertex AI (Gemini 1.5 Flash)
- **Infrastructure**: Google Cloud Run + Cloud Build

## Prerequisites

- Node.js 18+
- Google Cloud Project with Vertex AI and Firestore enabled.
- Google Cloud Credentials (ADC) configured locally (`gcloud auth application-default login`).
- `.env.local` file with secrets (Auth, Project ID).

## Setup

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Environment Variables**
   Create `.env.local`:
   ```bash
   AUTH_SECRET="your-generated-secret"
   AUTH_GOOGLE_ID="your-google-client-id"
   AUTH_GOOGLE_SECRET="your-google-client-secret"
   GOOGLE_CLOUD_PROJECT="your-project-id"
   GOOGLE_CLOUD_LOCATION="us-central1"
   ```

3. **Database Seeding**
   Initialize Firestore with exercises:
   ```bash
   npm run seed
   ```

4. **Run Development Server**
   ```bash
   npm run dev
   ```

## Infrastructure

- **Dockerfile**: Optimized for Cloud Run.
- **cloudbuild.yaml**: CI/CD pipeline configuration.

## Key Features

- **Conversational Interface**: Talk to the coach to build your profile.
- **GenAI Engine**: Training plans generated by Gemini, grounded in your profile.
- **Weekly Plans**: 4-week structured plans with progressions.
